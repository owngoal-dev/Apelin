Open in Apelin

This page opens a Git repository in Apelin from a button on a README or a web page. Apelin asks before it imports anything.

Git Repository
Branch
Open in Apelin

Apelin shows the address, the branch and the new project’s name, and imports nothing until you confirm. Nothing in the repository runs, and nothing is sent to your agent.

This link names no repository Apelin can import.

An Open in Apelin link carries the repository’s HTTPS address, with no user name, token, query or fragment in it, and optionally a branch. Ask whoever shared it for a corrected link.

Don’t have Apelin?

Apelin is an IDE for iPhone and iPad running custom firmware on iOS and iPadOS 16 or later. It installs from apt.owngoal.dev through Irisin, Apelin’s installer: add the source, install Apelin, then come back and tap Open in Apelin.

Add apt.owngoal.dev in Irisin

Or add apt.owngoal.dev in your preferred package manager. More about Apelin is on GitHub.

Add this button to a README

[![Open in Apelin](https://owngoal-dev.github.io/Apelin/open/badge.svg)](https://owngoal-dev.github.io/Apelin/open/?url=https%3A%2F%2Fgithub.com%2Fowner%2Frepository)

The link is https://owngoal-dev.github.io/Apelin/open/?url= and the repository’s HTTPS address, URL-encoded, with &branch= and a branch name to check out one other than the default. It carries nothing else: no command, no message for the agent and no credential. A private repository asks for a sign-in in Apelin.
