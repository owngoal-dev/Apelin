Apelin 0.4.7 always stops a chat when you tap Stop, keeps several OpenAI-compatible endpoints side by side, and captures a webpage from an address typed without https://.

- A chat could get stuck with no way to stop it or carry on: when a step was waiting on something that never answered, such as a git transfer on a stalled connection, a long build or a download, Stop did nothing and every new message waited behind it. Stop now ends the turn within a few seconds whatever the step is waiting for, and a build it was running stops with it. A git clone, fetch or push on a connection that has gone silent now fails after two minutes instead of waiting for ever. A chat that still does not stop is ended by Apelin and carries on from your next message.
- Model Providers kept a single OpenAI-compatible endpoint, so adding another replaced the first. You can now add as many as you need: each keeps its own key, address and models, they are listed by host, and the model menu shows each one's models under its host.
- Capturing a webpage with Web failed with "Invalid Web Address" unless the address began with https://. An address typed without it, such as example.com, now works, and when an address cannot be read the field comes back with what you typed.
- Model Providers did not say which version of kwwk, the library that signs in and talks to every provider, the app was built with. Its footer now does, which is the number to give when reporting a provider problem.
- Setting up Command Line Tools 27.0 failed, because Apple no longer serves its download. It is no longer offered: choose 27.2 instead. A 27.0 toolchain already on the device keeps working.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
