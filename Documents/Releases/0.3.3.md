Apelin 0.3.3 adds OpenCode as a model provider, keeps long chats going when they compact, marks the conversations you have not read, records each conversation's tool calls in Settings ▸ Logs, and gives the agent more room with git when you ask for it.

- A long chat stopped with "context is too large and compaction failed: Unsupported parameter: metadata", and Compact… failed the same way. Compaction no longer sends that parameter, so the chat goes on.
- OpenCode Go could not be signed in to, even as an OpenAI-compatible endpoint. OpenCode Go and OpenCode Zen are now in Model Providers: paste your OpenCode Console key and pick models, Chat, Responses, Anthropic and Gemini models alike. Kimi For Coding Global is there too.
- A reply that came while you were in another conversation was easy to miss. A conversation you have not read since its reply shows a yellow dot where its spinner was, and the project menu shows how many each project has, such as "Pineora - 3".
- With many projects, the project menu grew long. It now lists the five you used last, and the open one, with the rest under More Projects.
- After a compaction failed, Settings ▸ Logs held nothing about it. Each conversation now has its own log under Chats: every tool call from start to end with its outcome, approvals, model errors with their status, and each compaction. Search finds a call by its ID, and Share sends the log with keys, device names and your content left out.
- apelin-project.json was saved on one line. It is now written two spaces a level, and a build tidies one written otherwise; no value or order changes.
- Asked to force-push, the agent refused even with your go-ahead. It now force-pushes when you ask, with a lease, after a card in every mode shows the branch, what is overwritten and the commits that leave it, and stops if the remote changed. It can also squash commits you ask it to combine.
- A project with no remote could not be pulled into, and importing a repository that has its own apelin-project.json was refused. The agent can now add and change a project's remotes, make a project match a remote's branch when you ask (after a card in every mode, with your work saved to a backup branch first), and an imported repository's own apelin-project.json is used.
- A README can now carry an Open in Apelin button: it opens Apelin on a confirmation with the repository, branch and project name, imports it into a new project and opens it, running nothing and sending nothing to the agent.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
