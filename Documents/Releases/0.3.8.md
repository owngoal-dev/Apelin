Apelin 0.3.8 fixes toolchain setup failing at Extracting and brings back Command Line Tools 27.0.

- Setting up a toolchain could fail at Extracting because unpacking it took more memory than the device could give. This started in 0.3.6. Unpacking now takes about 100 MB. If a setup failed, start it again.
- Command Line Tools 27.0, the release with Swift 6.4, was missing from the list of toolchains to set up, because Apple's list moved on to a newer release that Apelin has not tested yet. Apelin now keeps offering the releases it has tested, whether or not Apple still lists them.
- A tweak can no longer use MSHookMessageEx to hook the few Apelin methods that pass raw data, because exposing them to the Objective-C runtime caused the memory problem above. Every other method can still be hooked.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
