Apelin 0.4.3 lets a package you build name its depiction, so a package manager shows its page and changelog.

- A package built in Apelin had an empty changelog tab in Sileo and Irisin, whatever its description said, because it could not name a depiction. A project can now set `package.depiction` (a web page) and `package.sileoDepiction` (the page Sileo and Irisin draw themselves, changelog tab included) in `apelin-project.json`, each an https address you host. Ask the agent for it: it has a new skill for writing the depiction and where to put it.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
