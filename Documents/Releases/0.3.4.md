Apelin 0.3.4 keeps builds working after a RootHide device restarts, and keeps your chats, toolchains and SDKs when one saved file can no longer be read.

- After a restart, every build on a RootHide device failed with "toolchain … has no runnable clang" and "SDK … is registered at a path that no longer exists", and the toolchain self-test asked you to set the toolchain up again. RootHide gives its folder a new name when the device restarts. The toolchain and SDK you set up are now found under the new name, so builds work again without downloading anything.
- Packages built before a RootHide restart could not be installed, shared or published to your package repository afterwards, and backups of files you edited stopped being listed. They are found under the new name too.
- Chats could disappear every time Apelin was opened, and a new chat could not be started outside a new project. One saved chat that could not be read stopped every chat from loading. That chat is now moved to `Chats/Unreadable` in Apelin's folder, the others load, and new chats start even if the chats folder cannot be read.
- One saved record that could not be read could take others with it: setting up a toolchain could remove the other toolchains from the list, an SDK could be deleted, and earlier builds, approvals or the Settings ▸ Git page could be lost. A record that cannot be read is now kept as it is, and everything else keeps working.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
