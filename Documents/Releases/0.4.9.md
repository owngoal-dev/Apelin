Apelin 0.4.9 brings Antigravity back to Model Providers, keeps chat compaction going when a provider's own compaction fails, and uses fewer tokens when compacting.

- Antigravity (Google's) was missing from Settings ▸ Model Providers in 0.4.8, and installing 0.4.8 removed any saved Antigravity sign-in and enabled models. Antigravity is listed again after Cursor, so you can sign in with your Google account in Safari and turn on models available to your plan (such as Gemini 4 Argon, Gemini 3.8 Flash, Claude Opus 5.5 and Claude Sonnet 5.5). If you used Antigravity before 0.4.8, sign in again and turn your models back on; signing out in Apelin removes the sign-in only from this device.
- When you chose Compact… in a chat's More menu, or a chat filled the model's context window, compaction failed if Claude's or OpenAI's compaction service was overloaded or returned an error (on Anthropic API keys, Claude Pro or Max, OpenAI API keys, and ChatGPT Codex). Apelin now falls back to writing the summary itself with the same model (via kwwk 0.1.127, the library Apelin uses to talk to every provider) so the chat is compacted and continues, stopping only if your sign-in is rejected (in which case, sign in again).
- When Apelin writes a compaction summary itself, long tool outputs from earlier in the chat traveled in full and the request was written to the provider's prompt cache even though nothing reads it again, billing extra tokens on API-key accounts. Long tool outputs older than roughly the last 60,000 tokens are now sent as a one-line note and the summary request is not cached.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.11.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
