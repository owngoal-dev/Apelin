Apelin 0.3.9 adds Command Line Tools 27.2, Apple's newest release.

- Command Line Tools 27.2 was missing from the list of toolchains to set up because Apelin had not tested it. It is now at the top of the list. Its C, C++ and Objective-C tools run where 27.0's do, and its Swift 6.4.2 needs iOS 26 or later and an A13 chip or later. Command Line Tools 27.0 stays in the list, and a toolchain you already set up is left as it is.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
