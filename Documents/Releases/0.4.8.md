Apelin 0.4.8 ends a turn as soon as an account reaches its usage limit or you tap Stop, lets you set token limits per API-key model, and lets the agent wake and unlock your device for testing.

- When an account's allowance ran out, such as GitHub Copilot's premium requests, Z.ai's or BigModel's five-hour, weekly or monthly limits or an expired plan, or a per-day limit such as OpenRouter's, the chat showed "Reconnecting…" for about a minute and a half while retrying eight times before saying "Too Many Requests", and a message sent meanwhile waited as long again. The turn now ends at once with "Usage Limit Reached" and the provider's own words under it, and a message you sent while it was working goes back into the input box with "Message Not Sent" so you can choose another model before sending it. Ordinary short rate limits are still waited out as before.
- In 0.4.7, a chat kept showing it was working however often you tapped Stop when a model request, a sign-in renewal or a compaction ignored the stop. Stop now always ends the turn: at once in the usual case, and if the reply has not stopped within 20 seconds Apelin ends it and the chat shows "Did Not Stop in Time" with "Apelin ended this reply. Send a message to continue."
- Apelin assumed one context window and one reply size for every model behind an API key, such as 131,072 and 32,000 tokens for any model of an OpenAI-compatible endpoint, while relays, gateways and providers serve other sizes, so chats compacted too late or too early, or replies were cut short or refused. Each model of an API-key account now has Token Limits in Settings ▸ Model Providers ▸ the account ▸ Models (the ⓘ button at the end of the model's row): set its Context Window and Maximum Output, or leave a field empty to use the automatic value shown in the field. Subscriptions are not affected.
- When a conversation could not be compacted to fit the model's context window, such as under a small Context Window set in Token Limits after the agent read a very large file, the chat ended on "Something Went Wrong" with technical internal wording about token counts and recovery targets. The chat now shows "Chat Too Long" and tells you what to do: compact the chat or start a new one, then send your message again.
- The agent could not wake and unlock a passcode-protected device to run automated screen tests. You can now enter this device's passcode in Settings ▸ Agent ▸ Device Passcode and tap Test and Save, which locks the screen and unlocks it with the passcode once; after that, the agent can wake and unlock the device for testing, still asking first as Ask Before Using the Screen and the permission mode say. The passcode stays in this device's keychain only, and because a wrong passcode counts as a failed attempt on the device, Apelin tries it only after a test passed and never twice in a row after a failure; a device without a passcode needs nothing, and this requires icli 0.11.0 or later.
- Installing a package or setting up a toolchain could fail with "Irisin is not responding. Make sure Irisin 4.7.3 or later is installed, then try again." even with a current Irisin installed, and reinstalling Irisin did not help, or an install could wait for ever on a background service that never answered. The message now says why when Apelin can tell: Irisin is missing, not completely installed or too old; Irisin's background service is missing, not loaded or does not answer (giving up after about 20 seconds); or Irisin refused Apelin because a folder or file on Apelin's path has unsafe permissions or ownership, which the message names with the fix. When another program is holding the package database and Irisin fails at once with "Installation stopped", the message now names that program so you can wait for it to finish.
- A conversation was only compacted automatically when it reached 75% of the model's context window, even if that happened in the middle of a task. The agent can now also compact the conversation itself at a good stopping point once the context is past half full, which Apelin suggests to it as the context fills; the conversation shows a Compacted row where it happened, as it does after the Compact… menu item, which you can tap to read the summary, and it asks you nothing and changes none of your files.
- Antigravity (Google's) is no longer offered in Model Providers, because kwwk, the library Apelin uses to sign in and talk to every provider, dropped it. Its saved sign-in and the models you enabled for it are removed from the device when you update, and a chat that had an Antigravity model selected uses another signed-in account's model, or asks you to choose one.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.11.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
